3. 智能体（重点 · v0.1.0）

按产品分组的连接卡片。组头显示「在线 a/b · 最近时间」与产品级「查看历史」。

3.1 页头操作

连接实例          [ 添加连接 ]  [ 查看全部历史会话 ]
按钮作用
添加连接选产品（Cursor / 豆包 / …）、备注、可选「专用 API 密钥」「认领历史」
查看全部历史会话打开历史页，不限产品与连接

3.2 产品组头

┌ Cursor / cursor ──── 在线 1/1 · 最近 …  [查看历史] ─┐

组头 查看历史：进入历史页并按该产品（agent）筛选，不限本连接。

3.3 连接卡片

│ ┌─ 公司PC ───────────────────────────────────────┐ │
│ │ [进程在线|离线]  [已注册连接]                    │ │
│ │ 公司PC                         [编辑]           │ │
│ │ [活跃 · …]  最近 …                              │ │

卡片按钮作用

查看回执行内展开最近召回回执

│ 当前范围：智能体 cursor · 仅连接 a1b2c3d4…           │
│ （或：不限连接 / 账号下全部会话）                      │
│ ┌ 列表 ──────────┐ ┌ 详情 ──────────────────────────┐ │
│ │ 标题 · agent   │ │ 开始于 … · 主智能体              │ │

6. 接 Cursor / 豆包（v0.1.0）

6.1 Cursor（Windows）

  1. 智能体 → 添加连接 → 产品 Cursor → 勾选专用 API 密钥 → 创建。
  2. 下载配置脚本，解压双击 .cmd（与 Cursor 同一 Windows 用户）。
  3. 或打开配置步骤：合并 hooks、MCP、credentials.json。
  4. 完全退出并重开 Cursor；历史中应出现新会话（钩子写入）。

说明见公开文档中的 Cursor 稳定安装说明。验证版本：Cursor Windows 3.27.14。

6.2 豆包（Windows 桌面 · 工作/Agent）

  1. 添加连接 → 产品 豆包 → 勾选专用密钥 → 下载配置脚本（尽量自动装 Skill）。
  2. 卡片上打开配置步骤，按字段复制到豆包连接器。
  3. 豆包 → 插件·技能·伙伴 → 新建自定义连接器 · STDIO。
  4. 表单逐项填写（不要把 JSON 整段贴进「命令」）：
    • 命令 = shared-memory-mcp.exe 的绝对路径
    • 参数留空
    • 环境变量：SHARED_MEMORY_API_URL / API_KEY / AGENT=doubao / CONNECTION_ID
  5. 技能「我安装的」中确认 shared-memory；新开工作任务，用 Skill 做 recall + ingest。
  6. 智能体页「活跃」更新后，再「查看历史会话」。
豆包没有静默 hook：普通闲聊窗口不会自动进平台。手机 App 不支持本方案。

7. PUBLIC_API_URL（部署必配）

配置脚本与控制台「配置步骤」里的 API 地址，来自 API 进程的 .env，不是前端写死域名。

# 仓库根目录 .env
HTTP_ADDR=:18080
PUBLIC_API_URL=http://你的域名:端口     # 客户端必须能访问到
# 本机同机调试可用：
# PUBLIC_API_URL=http://127.0.0.1:18080
  • 修改后重启 API。
  • 重新下载配置脚本，或改豆包连接器里的 SHARED_MEMORY_API_URL。
  • 控制台通过 GET /v1/me → public_api_url 展示。
  • 完整说明：部署指南中的 PUBLIC_API_URL 专节。
