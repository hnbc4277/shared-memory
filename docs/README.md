# 文档目录

文档按是否适合随公开仓库发布，分成两块：

| 目录 | 用途 |
|------|------|
| **[公开/](./公开/)** | 给使用者与外部贡献者：部署、API、手册、适配说明相关 |
|  |

发布到公开 GitHub 时：只推送适合公开的文档与代码；本地笔记勿提交。

## 公开/

- `DEPLOY.md` / `deploy/` — 部署与自托管
- `API.md` / `openapi.yaml` — HTTP API
- `manual/` — 操作手册与图文
- `migration/` — 迁移说明
- `ops/` — 验收清单
- `design/` — UI / 系统设计说明（注意截图勿含密钥）
